📖 My HTML Dictionary

Here are some important HTML terms from this lesson.

Semantic HTML
HTML that uses elements according to their meaning and purpose.
Emphasis
Used to give stress or emphasis to text.
Strong Importance
Used to show that some text is especially important.
Unordered List
A list where the order of the items does not matter.
Ordered List
A list where the order of the items matters.
Description List
A list containing terms and their descriptions.

💡 Quick Tip

Remember: HTML is about structure and meaning, not just how text looks.

Use <em> when you want to give emphasis, rather than using it only because it looks italic.
